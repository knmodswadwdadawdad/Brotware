# Brotware Studio

Editor visual de HTML inspirado no fluxo do Sketchware.

## Recursos atuais

- **View**: editor visual com drag & drop, grid, seleção, resize e layouts aninhados.
- **HTML Pages**: cada "Activity" é uma página `.html`.
- **Event**: lógica visual por eventos (`onClick`, `onInput`, `onChange`, etc.).
- **Actions**: abrir página, alert, alterar texto/CSS, mostrar/ocultar, variáveis e console.
- **Conditions**: cada ação pode ter uma condição simples baseada em variáveis.
- **Component**: biblioteca de componentes prontos e componentes salvos pelo usuário.
- **Strings**: recursos `@string/chave`.
- **Properties**: posição, tamanho, texto, cores, borda, padding, CSS customizado e navegação.
- **Import HTML**: cria uma nova página a partir de HTML existente.
- **Export**: página atual, todas as páginas e projeto `.brotware.json`.
- **Preview** e **código gerado**.
- **Autosave** em `localStorage`.
- **Undo/Redo** por página.
- Funciona sem bibliotecas externas.

## Como abrir

Abra `index.html` no navegador ou publique o repositório com GitHub Pages.

## Atalhos

- `Ctrl + S`: salvar
- `Ctrl + Z`: desfazer
- `Ctrl + Y`: refazer
- `Delete`: excluir widget
- Setas: mover widget 1px
- `Shift + setas`: mover 8px
